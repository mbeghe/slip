# Fuentes

**Baloo** solo se usa en el logo (`/logo.svg` como trazos vectoriales).

El texto del sitio usa **Nunito** (Google Fonts) para buena lectura en catálogo y admin.

Si más adelante querés una fuente custom para el cuerpo del sitio, agregá los archivos aquí y definí `@font-face` en `src/index.css`.
